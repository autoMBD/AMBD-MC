## 新增与修复

- 增加从固定 Git 提交生成 BLDC/PMSM 模型与源码包的工具，提供第三方许可清单、文件清单和 SHA256 校验和。
- 增加 Draft 优先的 GitHub 发布流程，核对上传附件与 GitHub 自动源码归档。
- 包含当前统一 `ambd_mc` 入口、主机场景、S32K344/S32K144 适配源码和配置；具体能力与适用限制见随包手册。

## 兼容性与使用

- 这是发布流程的首个候选包（Pre-release），请在新目录解压使用。源码/模型 ZIP 不含安装器或可直接烧写的固件。
- 参考环境为 Windows + MATLAB/Simulink R2026a + autoMBD HSP 0.1.0。HSP 及工具箱须自行安装；完整矩阵见随包 `docs/manual/index.md`。
- 使用 `ambd_mc("setup","pmsm")` 或 `ambd_mc("setup","bldc")`；首次运行不要重建模型或重置字典。详见随包快速开始。
- 从历史 v0.1.0 迁移时，采用当前目录结构和统一入口；不要将旧包、旧硬件回调或字典直接覆盖到新目录。

## 许可与限制

- 自有代码遵循 MIT；两个 HSP 目标配置保留 Apache-2.0 许可、来源和修改记录。
- 不包含 `legacy/`、厂商 RTD/SDK 实现、工具安装包、生成代码/固件或内部运行记录。
- 打包检查不执行 MATLAB，不代表 SIL、目标构建、PIL 或带电机试验已通过。本候选包不对这些目标能力作新增验收声明；使用前按各场景指南自行验证。
- 开发者打包/发布工具需要 Git 检出；解压包中的普通初始化与主机场景不需要 Git。需要维护者工作流时，请克隆对应 tag。

## 校验与反馈

将 ZIP 与 `SHA256SUMS` 一同下载，校验成功后解压。问题反馈请附版本、场景、环境和脱敏错误信息；不要上传内部原始日志、凭据或受限文件。
