## 验证边界

PIL 验证的是目标处理器执行代码的输入／输出行为；这里没有完成真实电机
功率板闭环和执行周期测量。随附 EB 工程的 ADC 为控制板内部参考通道，
`Hsp_MotorSamples` 仅作诊断，尚未连接到控制器根输入。默认输出未解锁。

实际功率板接入仍需要明确板卡与电机型号、接线、采样标度、驱动器初始化、
互补 PWM／死区和逐相两管关断真值表，并实现采样输入桥。
`Pwm_SetOutputToIdle` 仅设置单路固定电平，不能作为 BLDC 悬空相高阻的证明。
板级采样桥联调、功率级输出验证和真实电机闭环标记为 **SKIP／阻断**：
适配尚未完成，所需板卡与接线信息尚未确认。本报告不能证明真实电机已经可运行。

原生构建保留了 NXP 预编译 C／数学库与目标枚举尺寸不一致的链接警告，
未关闭警告或修改第三方库。测试是否通过与这些警告分别记录。

MATLAB Code Analyzer 对 `ambd.validate_pil` 中由 `evalc` 赋值的
`normal`、`target` 报告两处可能未初始化警告；仿真异常路径在读取这些值前
重新抛出异常。该项作为静态检查警告保留，不记为零警告检查。

模型与源码指纹、ELF 指纹及比较摘要见
[可追溯证据 JSON](2026-10-07-hsp-s32k344.json)。指纹为验证时文件字节的 SHA-256。
复现入口及配置说明见 [S32K344 HSP 指南](../hsp-s32k344.md)。
