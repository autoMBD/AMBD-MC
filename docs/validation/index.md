# 验证记录与适用范围

本目录保存已执行工作的历史摘要和技术决策，不是当前工作区的自动通过证明。
每份报告中的日期、运行编号、工具版本和源码指纹共同定义其适用基线。
修改代码或模型后，应按当前指南重新运行需要的检查。

## 按层次阅读

| 层次 | 证明什么 | 不能替代什么 |
| --- | --- | --- |
| 单元／对象参考 | 算法局部行为、物理方程与独立参考一致性 | 完整控制闭环 |
| Normal/SIL 闭环 | 模型及主机生成 C 的控制行为 | 同输入数值等价 |
| 同输入重放 | 相同输入下状态、时序和输出比较 | 两个独立闭环的物理表现 |
| 目标 PIL | 实际处理器执行生成代码及数值比较 | 连续实时电机试验 |
| 控制板诊断 | 当次板级采样、提交及故障状态时序 | 正常运行 WCET、功率级和带载闭环 |

## 原始工件与复现

原始 JSON、MAT、日志、图片和生成代码位于运行机器的忽略目录 `.agent-env/`。
报告中的本地路径用于追溯，不是网站附件；本站仅发布已纳入文档的摘要和明确的
证据 JSON。原始工件若已清理，需重新运行并产生新的运行编号，不能声称恢复了
相同历史证据。

复现入口见[验证教程](../tutorials/tutorial-advanced.md)和 [HSP 指南](../hsp-s32k344.md)。
缺少输入或硬件时记录 SKIP；未验证项目保留其原因。
