# 贡献指南

项目贡献流程统一维护在
[仓库贡献指南](https://github.com/autoMBD/AMBD-MC/blob/main/.github/CONTRIBUTING.md)。
请在提交中说明问题、改动范围、实际测试结果和关联 issue。

文档改动遵循[文档维护与发布](../development/documentation.md)：运行严格构建和链接检查，
更新导航与引用。涉及类型源时还需核对工程输入契约；
纯文字或站点配置更新不意味着模型重新通过运行验收。

提交代码、日志或附件前核对[许可范围](license.md)，保持机器配置与运行工件在
`.agent-env/`。不要从历史受限目录复制内容到站点。
