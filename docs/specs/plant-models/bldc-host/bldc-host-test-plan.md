# BLDC host plant test plan

Tests use public interfaces and analytically derived expectations, not golden
traces generated by the implementation. RL locked rotor checks exponential
response; free coast checks viscous exponential speed; all-off checks passive
energy and exact release at zero current. Commutation checks winding current
continuity and KCL to 1e-12 A. Signed torque cases cover all six sectors.
Open terminal voltage checks both rotation directions and zero crossing slope.
Numerical convergence compares 10 and 20 substeps against 80 at identical
sample times, demanding reduced error. Torque/BEMF power consistency is
checked independently from normalized phase shape values.

Native reference comparisons use MathWorks Simscape BLDC with explicit BEMF
table parameterization to remove flux convention ambiguity. Ideal physical
switches and antiparallel diodes preserve floating terminal behavior. Native
source uses no bldc plant helper. Lock/drive shaft motion explicitly for
electrical cases; compare commutation and all-off current trajectories and
PWM interval means as separate fidelity checks. Predetermined tolerances:
open BEMF 1e-4 V, unmodulated RL 0.01 A, diode/commutation 0.03 A, PWM mean
0.1 A; switching ripple is reported separately. Reports require actual
execution and never infer PASS from toolbox availability.

The native foundation switch/diode blocks require finite on resistance,
positive diode threshold and finite off conductance. The reference uses
0.1 milliohm on resistance, 0.1 mV diode threshold and 1e-8 S off conductance
per device. Its local backward Euler step is Ts/100 for driven cases and
10 us for the prescribed-speed open-circuit profile. Current dq targets are
explicitly high-priority zero; allowing unconstrained initial currents is
not an acceptable reference initialization.

With all six switches off, four off-conductance paths meet each phase.
An exact zero initial winding current therefore produces an RL boundary
layer with L/(R+1/(4Goff)) time constant. Open-circuit validation compares
native internal BEMF against the independent phase table, and measured
winding voltage against the analytic finite-leakage transient, including
t=0. No initial sample is excluded. Native electromagnetic torque is also
checked against Ke times the dot product of independently interpolated
phase shapes and measured currents, within 1e-6 N m.

## Terminal-voltage and carrier-frequency qualification extension

Before evaluating new traces, the following windows and limits are fixed.
For each shaft direction, excite phase C for 1 ms and then hold the A/B pair
active with C floating. Shaft speed is ±100 mechanical rad/s; the electrical
angle is set so C BEMF crosses zero at exactly 3 ms. Positive rotation uses
A+ C- then A+ B- (upper-diode C release); negative rotation uses C+ A- then
B+ A- (lower-diode C release). Stop at 4 ms. Host acquisition is 16 kHz.

- The pre-existing current-error limit remains 0.03 A.
- The voltage qualification starts two fast samples after commutation.
  A clamped sample requires both independently measured floating currents
  to exceed 0.05 A in magnitude; a floating sample requires both currents
  below 1e-5 A. These windows are computed from currents, not voltage error.
  Require at least two clamped samples and 20 floating samples, plus valid
  samples on both sides of the expected crossing. Empty windows fail.
- Absolute floating-phase terminal-voltage difference must be below 5 mV
  in both clamped and released windows. The clamped voltage must also agree
  with its physical rail to 5 mV.
- Each current-release time must exist, and host/native current-release and
  voltage-release times must agree within one fast sample plus two native
  integration steps. All post-commutation samples remain in saved traces;
  the transition itself is qualified by these independent event-time checks.
- Exactly one qualified falling crossing is required in both directions.
  Host/native crossing times and each crossing against the imposed 3 ms
  crossing must be within one fast sample. A fit over ±2 fast samples about
  3 ms must have the theoretical slope -6 Ke polePairs omega_m^2/pi within
  5 percent. No trace-dependent tolerance or window adjustment is allowed.
- Negative fixtures must reject voltage bias, reversed slope, a crossing
  delayed by two samples, delayed diode release, and no usable samples.

Retain the 16 kHz carrier case and add 32 kHz using the same quantized duty,
bus and load. Use 100 native steps per carrier period. Both settled mean
errors (3–10 ms) must stay below 0.1 A. Compare the mean per-cycle peak-to-peak
ripple in the common settled window: the 32/16 kHz ratio must lie in
[0.4,0.6]. This qualifies the expected first-order ripple reduction; no
claim is made that mean error decreases when discretization dominates it.

## Acceptance integrity

Before any qualification mask, reject malformed measurement structs,
nonfinite or complex entries anywhere in either current/voltage trace,
nonfinite timestamps, duplicate or non-increasing times, inconsistent
three-phase dimensions, uncovered host times and inconsistent acquisition
or event metadata. This includes samples outside the voltage qualification
windows and native samples that do not coincide with a host sample.

Only the Python entry point publishes authoritative `results.json` PASS.
It archives the prior attempt, writes RUNNING with pass=false, and removes
old current hashes/provisional data before prerequisite imports or Smoke
lookup. MATLAB writes a separate PROVISIONAL `native-results.json` carrying
the current attempt ID. Python validates that ID and physical result, checks
source stability, atomically writes hashes, rechecks source stability, then
atomically publishes final PASS bound to the hashes and provisional report
by SHA-256. Any exception records FAILED with pass=false and removes current
hashes. Previous evidence remains archived.

Run the Python failure-path suite before the real native reproduction:

```powershell
python -m unittest discover -s tests/bldc -p test_plant_reference_runner.py -v
python tools/bldc/validate_plant_reference.py
```

The Python suite uses isolated temporary directories and mocked MCP
responses solely to inject prerequisite, import, source-change, hash-write
and provisional-report failures. It is not native physics evidence; the
second command still requires the real fresh-session Simscape execution.
